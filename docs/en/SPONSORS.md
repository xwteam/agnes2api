Find this helpful? Give the project a Star — that is the most direct way to support an open-source maintainer.

## 💖 Support the Project

agnes2api is an open-source project maintained primarily by an individual. If this project helps you, consider supporting it through:

- ⭐ Star the project
- 🔗 Share with friends who might need it
- 🐛 Submit an [Issue](https://github.com/xwteam/agnes2api/issues) to report bugs or suggestions
- 🔧 Submit PRs to contribute code or documentation

---

## 🤝 Contributing

1. Fork this repository
2. Create a branch `git checkout -b feature/your-feature`
3. Commit code `git commit -m "feat: add something"`
4. Push and create a Pull Request

**Contribution Areas:**

- 🔌 Compatibility testing for new protocols (OpenAI / Anthropic / Gemini / OpenAI-Responses)
- 🖼️ Broader image and video forwarding coverage
- 🔐 Public-facing shape and hardening of the registrar (P2)
- 🌐 Multi-language translation improvements
- 📖 Documentation improvements
