# ☕ 후원 & 기여

도움이 되셨나요? 프로젝트에 스타를 눌러 주세요. 오픈 소스 메인테이너에게 가장 직접적인 응원이 됩니다.

---

## 💖 프로젝트 지원

agnes2api는 주로 개인이 유지 관리하는 오픈 소스 프로젝트입니다. 이 프로젝트가 도움이 되었다면 다음과 같은 방법으로 지원해 주세요:

- ⭐ 프로젝트에 스타 주기
- 🔗 필요한 친구들과 공유하기
- 🐛 버그나 제안을 [Issue](https://github.com/xwteam/agnes2api/issues)로 제출하기
- 🔧 코드나 문서를 PR로 기여하기

---

## 🤝 기여하기

1. 이 저장소를 포크하기
2. 브랜치 생성 `git checkout -b feature/your-feature`
3. 코드 커밋 `git commit -m "feat: add something"`
4. 푸시 및 풀 리퀘스트 생성

**기여 분야:**

- 🔌 새로운 프로토콜 호환성 테스트 (OpenAI / Anthropic / Gemini / OpenAI-Responses)
- 🖼️ 이미지·비디오 전달 기능 보완
- 🔐 레지스트라(P2)의 공개 형태와 보안 강화
- 🌐 다국어 번역 개선
- 📖 문서 개선
