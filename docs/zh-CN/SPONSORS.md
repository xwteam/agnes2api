## 💖 支持项目

agnes2api 是一个开源项目，主要由个人维护。如果这个项目对你有帮助，欢迎通过以下方式支持：

- ⭐ 给项目点个 Star
- 🔗 分享给有需要的朋友
- 🐛 提交 [Issue](https://github.com/xwteam/agnes2api/issues) 反馈 bug 或建议
- 🔧 提交 PR 贡献代码或文档

---

## 🤝 参与贡献

1. Fork 本仓库
2. 创建分支 `git checkout -b feature/your-feature`
3. 提交代码 `git commit -m "feat: add something"`
4. 推送并创建 Pull Request

**贡献方向：**

- 🔌 新协议兼容性测试（OpenAI / Anthropic / Gemini / OpenAI-Responses）
- 🖼️ 图片、视频转发能力完善
- 🔐 注册机（P2）的公开形态与安全加固
- 🌐 多语言翻译完善
- 📖 文档改进
