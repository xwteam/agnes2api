# ☕ サポート & 貢献

役に立ちましたか？プロジェクトにスターを付けてください。オープンソースのメンテナーにとって最も直接的な支援になります。

---

## 💖 プロジェクトをサポート

agnes2apiは主に個人によって維持されているオープンソースプロジェクトです。このプロジェクトがお役に立った場合は、以下の方法でサポートをご検討ください：

- ⭐ プロジェクトにスターを付ける
- 🔗 必要としている友人と共有する
- 🐛 バグや提案を[Issue](https://github.com/xwteam/agnes2api/issues)で報告する
- 🔧 コードやドキュメントをPRで貢献する

---

## 🤝 貢献する

1. このリポジトリをフォークする
2. ブランチを作成する `git checkout -b feature/your-feature`
3. コードをコミットする `git commit -m "feat: add something"`
4. プッシュしてプルリクエストを作成する

**貢献分野：**

- 🔌 新しいプロトコルの互換性テスト（OpenAI / Anthropic / Gemini / OpenAI-Responses）
- 🖼️ 画像・動画転送機能の拡充
- 🔐 レジストラ（P2）の公開形態とセキュリティ強化
- 🌐 多言語翻訳の改善
- 📖 ドキュメントの改善
